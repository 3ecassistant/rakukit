【⑨ 楽天市場 商品属性×競争力分析ツール 仕様書】

■① ツール名称

楽天市場 商品属性×競争力分析ツール

仮称：
Rakuten Attribute Competition Analyzer

■② 目的

楽天市場の商品検索APIとAttribute Search APIを組み合わせ、

・商品属性
・属性別商品数
・価格
・レビュー
・ショップ数
・送料条件
・商品別ポイント
・API標準順上位帯への出現状況

を分析し、

**「どの属性を持つ商品群が競争過密で、どの属性の商品群に比較的競争余地があるか」**

を定量化する。

2026-07-01版の商品検索APIでは`attributeFlag=1`を指定することで属性情報を取得できる。ただし、この機能を利用する場合は`genreId`を0以外で指定する必要がある。商品単位では`attributeIds`も出力される。

■③ 想定利用者

・楽天市場出店者
・商品企画担当者
・商品開発担当者
・MD担当者
・マーケティング担当者
・楽天SEO担当者
・競合分析担当者

■④ このツールの中心価値

例えば、

「トートバッグ」

という市場全体を見るだけでは、

レビュー：

→ レビュー多

→ レビュー少

など、

そこで、

商品市場

↓

属性単位に分解

↓

価格・レビュー・ショップ競争を比較

する。

×
