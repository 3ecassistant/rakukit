# 楽天市場 商品登録支援ツール群 詳細仕様書

## 1. プロジェクト概要

### 1-1. 目的

楽天市場の店舗運営担当者が、商品登録・商品更新時に発生する細かな確認・加工・CSV編集作業を、Excelや専用ソフトを開かずブラウザ上で完結できるサービスを構築する。

対象機能は以下の15ツール。

1. 商品名文字数チェッカー
2. キャッチコピー文字数チェッカー
3. 全角／半角文字数チェック
4. 禁止文字／機種依存文字チェック
5. HTMLタグチェッカー
6. HTML整形
7. HTMLタグ除去
8. 改行コード変換
9. 商品説明文HTML生成
10. CSV文字コード変換
11. CSV列抽出
12. CSV列結合
13. CSV差分比較
14. CSV重複削除
15. CSV一括置換
16. CSV→Excel変換

# 7. 禁止文字／機種依存文字チェック

## 7-1. 目的

商品登録時の文字エラーや文字化け原因を事前検出する。

## 7-2. チェック対象

* 機種依存文字
* 制御文字
* 不可視文字
* 特殊Unicode
* 絵文字
* サロゲートペア
* 特殊スペース
* 改行
* タブ

## 7-3. 判定

3段階。

### OK

問題なし。

### WARNING

使用環境によって問題になる可能性。

### ERROR

登録用途では使用を避けるべき文字。

## 7-4. 楽天ルール管理

禁止文字をプログラム内へ直接書き込まず、

**ルールマスター**

として管理する。

例：

* ルールID
* 対象項目
* 対象文字
* 判定
* 理由
* 代替候補
* 適用開始日
* ルールバージョン

楽天側の仕様変更時にプログラム本体を変更せず更新できる構成とする。

## 7-5. 修正

例えば、

`㈱`

↓

`(株)`

など代替文字候補を表示できる設計とする。

## 17-3. 判定

以下に分類。

### 新規

### 削除

旧CSVだけに存在。

完全一致。

## 17-5. フィルター

* 削除のみ
* 変更ありのみ
* 特定列変更のみ

## 17-6. 出力

各ツールを完全に独立して作らない。

共通処理基盤として、

**Input**
↓
**Parse**
↓
**Validate**
↓
**Transform**
↓
**Preview**
↓
**Export**

を作る。

例えばCSVを一度読み込めば、

* 文字コード変換
* 列抽出
* 列結合
* 重複削除
* 一括置換
* Excel出力

# 【重要まとめ】

このカテゴリーでは、16個の小さなツールを単独開発するより、

**「楽天商品登録支援ワークスペース」**

として共通基盤を作る。

特に重要なのは、

**商品名チェック**
＋
**CSV加工**
＋
**CSV差分比較**

の3本。

無料ユーザーには軽量な文字・HTML・CSVツールを提供し、PROでは、

* 大量CSV
* 差分比較
* Excel出力
* 複数ファイル
* プリセット
* バッチ処理

を解放する。

これなら初期は単純な便利ツールとして開始しつつ、後から楽天市場出店者向けの本格的な業務SaaSへ拡張できる。
