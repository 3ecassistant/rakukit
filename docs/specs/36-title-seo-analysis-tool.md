【② 楽天SEO競合タイトル分析ツール 仕様書】

■① ツール名称

楽天SEO競合タイトル分析ツール

仮称：
Rakuten SEO Title Analyzer

■② 目的

楽天市場の商品検索キーワードを入力すると、楽天市場商品検索APIから競合商品を取得し、

・競合タイトルで頻出するキーワード
・キャッチコピーで頻出するキーワード
・上位商品ほど使用率が高いキーワード
・競合には多いが自社商品には存在しないキーワード
・不要な重複ワード
・商品特徴ワード
・用途ワード
・ターゲットワード
・スペックワード

を自動抽出する。

最終的には、

「自社商品の商品名・キャッチコピーで、どのキーワードを追加・削除・優先すべきか」

を判断できる状態にする。

楽天市場商品検索APIではkeywordによる検索ができ、商品ごとにitemName、catchcopy、itemCaption、itemCodeなどを取得できる。

■③ 想定利用者

・楽天市場出店者
・楽天SEO担当者
・商品ページ制作担当者
・マーケティング担当者
・商品企画担当者

■⑥ 取得件数

選択式：

・30件
・100件
・300件

初期値：

100件

APIは1ページ最大30商品、最大100ページまで取得可能。

MVPでは最大300商品とする。

理由：

SEOタイトル分析では数千商品を分析するより、

「API標準順の比較的上位に位置する商品群」

のワード傾向を見ることを優先する。

基本：

＋

必要な場合：

を追加する。

「API標準順 上位商品」

■⑨ SEO分析対象テキスト

基本分析対象：

① itemName
② catchcopy

API公式仕様ではitemNameとcatchcopyが別項目として返され、通常名称を表示する際にはcatchcopy + itemNameを使用する旨が記載されている。

そのため本ツールでは、

商品名分析
キャッチコピー分析
商品名＋キャッチコピー分析

を分離する。

■㊷ 重要な分析原則

このツールでは、

「競合が使っているキーワード」

と

「検索需要があるキーワード」

を明確に区別する。

であって、

ではない。

したがって、

× 検索ボリューム

ではなく、

○ 競合商品使用率

として扱う。

「楽天SEOの正解キーワードを教えること」

ではない。

「API標準順に並ぶ競合商品の商品名・キャッチコピーを大量分析して、競合市場でどの言葉・訴求軸・組み合わせが多く使われているかを定量化すること」

を価値とする。

基本構成は、

検索キーワード
→ 競合100商品取得
→ 商品名・キャッチコピー解析
→ 頻出ワード
→ 商品使用率
→ 上位偏重ワード
→ 自社商品との差分
→ 追加候補

とする。

特に重要なのは、

「出現回数」ではなく「何％の商品がそのワードを使用しているか」

を主要KPIにすること。

また、

競合使用率が高い
＝
検索需要が高い

とは扱わない。

この区別を守ることで、かなり実用性の高い楽天SEO競合分析ツールになる。
