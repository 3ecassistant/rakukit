■① ツール概要

・設定したリピート売上目標に対して、現在のリピート売上と平均再購入単価から、あと何件の再購入注文が必要かを逆算するツール。

・中心となる問いは、

「リピート売上100万円まで、あと何件の再購入が必要？」

「現在60万円、平均再購入単価5,000円なら、あと何件必要？」

「平均再購入単価を6,000円とした場合、必要件数は何件まで減る？」

とする。

・㉑「リピート率目標・必要リピーター数シミュレーター」が顧客人数を扱うのに対し、㉒は再購文件数を扱う。

・今後候補として想定されている「リピート売上目標に必要な再購入件数」を独立ツール化する。

・実際に再購入が何件発生するかは予測しない。

・あくまで、

「設定した平均再購入単価を前提として、リピート売上目標を成立させるために必要な再注文件数」

を逆算する。

■② このツールの目的

・「リピート売上を100万円にする」という金額目標を、「あと80注文」という具体的な行動KPIへ変換する。

・リピート売上を売上額だけで管理せず、必要な再購文件数まで分解する。

・CRM施策、メルマガ、LINE、クーポン、購入後フォロー等を検討する前に、必要件数を明確化する。

・㉑でリピーター人数を管理し、㉒で再購文件数を管理することで、

顧客数

と

購入回数

を分離して評価できるようにする。

【重要まとめ】

㉒「リピート売上目標・必要再購文件数シミュレーター」は、

現在のリピート売上と平均再購入単価から、

目標リピート売上までに必要な追加再購文件数を逆算する一問一答型ツール。

−

÷
平均再購入単価
)
