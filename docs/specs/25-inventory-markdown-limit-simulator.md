■① ツール概要
・在庫を期限内に消化したい商品について、
・現在在庫
・現在価格
・商品原価
・送料
・現在日販
・消化期限
・許容できる総利益減少額
または
・最低確保したい総利益
を入力し、

→ 現在価格完売時利益
→ 値下げに使える利益原資
→ 1個あたり許容値下げ負担
→ 利益条件上の最低販売価格
→ 最大値下げ額
→ 最大値下げ率
→ 候補価格別完売利益
→ 期限内消化に必要な日販

を算出する。

中心表示：

「在庫300個で総利益を最大10万円まで削ってよい場合、利益条件上は1個あたり333円、最大6.7%まで値下げ余力あり」

とする。

■② このツールの目的
・前ツール⑬では、

「在庫300個を30日で消化するには10個/日必要」

という販売ペースを算出した。

次に実務で発生するのは、

「では、その在庫を消化するために価格をどこまで下げてもよいか」

という判断。

ただし、

価格を下げれば何個売れるかは予測できない。

そこで本ツールでは、

販売数増加を予測するのではなく、

店舗側が許容できる利益減少額から、値下げ可能な上限を逆算する。

■③ 最重要コンセプト
・値下げ可能額を、

「なんとなく20%OFF」

ではなく、

在庫全体で失ってよい利益額

から逆算する。
