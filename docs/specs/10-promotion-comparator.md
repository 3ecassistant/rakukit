# 楽天市場 ポイント vs クーポン比較ツール 詳細仕様書

## 1. プロジェクト概要

### 1-1. 目的

楽天市場で販促施策を検討する際に、

* 500円OFFクーポン
* 1,000円OFFクーポン
* 5%OFFクーポン
* 10%OFFクーポン
* ポイント5%
* ポイント10%
* ポイント20%

など複数施策を同時に比較し、

**「顧客への還元額はいくらか」**

**「店舗側の負担はいくらか」**

**「最終的に利益はいくら残るか」**

を即座に確認できるWebツールを構築する。

単に「10%OFFとポイント10%はどちらがお得か」を比較するのではなく、

**顧客メリットと店舗採算を同じ画面で比較する**

ことを目的とする。

---

# 2. コンセプト

販促施策では、

**顧客にとってのお得さ**

と

**店舗にとっての負担**

は必ずしも一致しない。

例えば、

販売価格：

5,000円

の場合、

500円OFFクーポン

と

ポイント10%

は顧客への還元規模が近く見える。

しかし、

* クーポン適用後売上
* ポイント店舗負担
* 売価連動手数料
* 原価
* 送料
* 広告費

まで考えると、店舗に残る利益は異なる可能性がある。

本ツールでは、

**顧客還元**
＋
**店舗負担**
＋
**利益**

を同時に比較する。

---

# 3. 既存ツールとの関係

既存の、

**利益・値引きシミュレーター**

および、

**SALE・クーポン採算チェッカー**

の計算エンジンを再利用する。

共通モジュール：

`ProfitCalculator`

を利用し、

本ツールでは、

**PromotionComparator**

を追加する。

---

# 4. 本ツールの役割

利益・値引きシミュレーター：

→ 1つの商品・条件を詳細に計算

SALE・クーポン採算チェッカー：

→ SALE施策の採算確認

ポイント vs クーポン比較：

→ **複数の販促施策を横並びで比較**

という役割分担にする。

# 25. ポイント施策の顧客支払額

# 26. 「支払額」と「実質負担相当」を分ける

重要仕様。

クーポン：

販売時に直接値引き。

ポイント：

後日利用可能なポイント等による還元。

そのため、

### 顧客支払額

と

### 還元考慮後の実質負担相当

を別項目として表示する。

# 31. 店舗負担額と利益減少額は同じとは限らない

重要。

例えばクーポンで販売価格が下がると、

売価比例型の販売関連費も下がる。

そのため、

500円OFF

↓

利益も必ず500円減る

とは限らない。

必ず施策適用後条件で利益を再計算する。

# 103. 重要な注意事項

本ツールで比較するのは、

**1注文あたりの採算**

である。

例えば、

ポイント10%

利益：

1,300円

500円OFF

利益：

1,400円

だからといって、

「500円OFFの方が施策として優れている」

とは判定しない。

ポイントとクーポンでは、

* 利用率
* 集客力
* CVR
* 再購入
* 顧客心理

が異なるため。

本ツールでは、

**同条件で1注文発生した場合の利益比較**

までとする。

＋

を入力して、

**10%OFF**

**商品保存**

**CSV一括比較**

**RPP・SALE・クーポン分析連携**

へ拡張すれば、販促施策を利益ベースで判断するツール群として強くなる。
