# CVR別CPC上限マトリクス 詳細仕様書

## 1. プロジェクト概要

### 1-1. 目的

RPP広告などのクリック課金広告を運用する際に、

* 販売価格
* 商品原価
* 送料
* 販売関連費率
* 最低利益率

を入力するだけで、

**CVRごとに許容できる最大CPCを一覧表示するWebツール**

を構築する。

例えば、

CVR1%

CVR2%

CVR3%

CVR4%

CVR5%

それぞれについて、

**利益率10%を維持できるCPC上限**

を同時に表示する。

---

# 2. コンセプト

広告担当者がCPCを判断する際、

**CPCだけでは高い・安いを判断できない。**

同じ商品でも、

CVR1%

と

CVR5%

では、

許容できるCPCが大きく異なる。

例えば、

CPA上限：

1,200円

の場合、

CVR1%

↓

CPC上限：

12円

CVR2%

↓

24円

CVR3%

↓

36円

となる。

本ツールでは、

**CVRが変化した場合にCPC上限がどう変わるか**

をマトリクス形式で表示する。

---

# 3. 最重要メッセージ

画面上で最も重要なのは、

# CVR2%ならCPC上限24円

# CVR3%なら36円

# CVR4%なら48円

のような比較。

これにより、

**商品ページCVRが上がれば広告入札余力がどれだけ増えるか**

を直感的に確認できる。

# 6. 前ツールとの関係

前ツール：

**RPP必要CVRシミュレーター**

では、

CPC

↓

必要CVR

を算出した。

本ツールでは逆に、

CVR

↓

最大CPC

を算出する。

つまり、

### RPP必要CVR

「CPC30円ならCVR何％必要？」

### CVR別CPC上限マトリクス

「CVR2%ならCPC何円まで？」

という役割分担にする。

# 67. 「推奨CPC」とは呼ばない

重要。

本ツールが算出するのは、

**利益条件から計算したCPC上限**

である。

競争環境・広告表示機会を考慮した最適入札値ではない。

そのため、

× 推奨CPC

○ CPC上限

と表記する。

# 115. 商品ページ改善とのつながり

CVR：

2%

↓

3%

へ改善。

↓

CPC上限：

24円

↓

36円。

つまり、

**CVR＋1pt改善によって、広告入札余力が＋12円増える**

という見方ができる。

これにより、

商品ページ改善と広告運用を別々に考えず、

**CVR改善 → CPA改善 → CPC余力増加**

という流れで理解できる。
