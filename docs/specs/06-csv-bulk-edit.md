# 楽天市場 CSV商品一括編集ツール 詳細仕様書

## 1. プロジェクト概要

### 1-1. 目的

楽天市場の商品登録・更新で使用するCSVをブラウザ上で読み込み、複数商品のデータを安全かつ効率的に一括編集できるWebツールを構築する。

ExcelやCSVエディタを使わなくても、

**CSVアップロード**
↓
**編集条件設定**
↓
**変更対象確認**
↓
**一括編集**
↓
**変更前後差分確認**
↓
**CSVダウンロード**

までを1画面で完結させる。

---

# 2. コンセプト

単なる汎用CSV編集ツールではなく、

**楽天市場の商品CSV編集に特化した業務ツール**

として設計する。

特に重視するのは以下。

* 大量商品の一括編集
* 誤更新防止
* 商品コード単位での確認
* 商品名・キャッチコピー編集
* SEO改善との連携
* 条件指定編集
* 編集前後の差分確認
* 元CSV構造の維持

Web Workerの利用を検討する。

処理中も、

* 進捗
* 中断

が操作可能な構成にする。

# 73. 進捗表示

### CSV処理中

48%

# 74. 中断

ユーザーが処理を中断できる。

途中結果については、

一括編集の場合は原則確定せず、

元データへ戻す。

# 81. MVP完成条件

以下を満たした時点をVer.1.0とする。

* CSVをアップロードできる
* Shift_JIS / UTF-8を扱える
* CSV内容をプレビューできる
* 列を選択できる
* 文字列を一括置換できる
* 文字列を追加できる
* 文字列を削除できる
* 条件に一致する行のみ編集できる
* 商品コード指定で絞り込める
* 変更前後を確認できる
* 変更件数を確認できる
* 警告・エラーを確認できる
* 元CSVへ戻せる
* CSVとしてダウンロードできる
* 先頭0やHTML等を破壊しない

# 82. 最重要UX

ユーザーにCSV関数やプログラムを書かせない。

基本操作は、

**① CSVを入れる**

↓

**② 何を変えるか選ぶ**

↓

**③ どの商品を対象にするか選ぶ**

↓

**④ 変更前後を見る**

↓

**⑤ CSVを出す**

だけにする。

---

# 83. 最重要安全設計

本ツールでは、

**編集能力より「間違えないこと」を優先する。**

必ず、

* 対象件数
* 変更前
* 変更後
* 警告
* エラー

を見せてからファイルを出力する。

特に価格・商品名・商品コード等の重要項目について、

ユーザーが意図しない全件変更を起こしにくいUIとする。

# 【重要まとめ】

MVPの核は、

**CSVアップロード**
＋
**対象列選択**
＋
**条件指定**
＋
**一括置換・追加・削除**
＋
**変更前後プレビュー**
＋
**CSV出力**

の6機能。

最重要なのは、

**「大量に編集できること」ではなく「大量編集しても間違えにくいこと」**

である。

既存の、

**サジェスト収集**
→
**トレンド分析**
→
**商品名SEOチェッカー**

と連携し、

次の段階では、

**SEOチェッカーで選択したキーワードを商品コード別にCSVへ一括反映する**

機能を追加する。

これにより、キーワード調査から実際の商品データ更新までを一連の楽天SEOワークフローとして提供できる。
