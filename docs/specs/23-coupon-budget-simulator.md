■① ツール概要
・クーポン施策を実施する際に、
・クーポン額
・発行／利用上限
・想定利用数
・販売価格または平均注文単価
・原価率
・送料
・販売関連費率
・最低利益率
を入力し、

→ クーポン総負担額
→ 必要売上
→ 必要注文数
→ クーポン利用1件あたり利益
→ 全体利益
→ 利益維持に必要なクーポン経由売上
→ 設定予算で何件までクーポンを利用させられるか

を算出する。

中心表示は、

「500円OFFを100件利用された場合、クーポン原資50,000円。利益率10%を維持するにはクーポン経由売上○円以上必要」

とする。

■② このツールの目的
・クーポンを作るときに、
「500円OFFを出したい」
「100枚限定にしたい」
「クーポン予算を5万円以内にしたい」
といった条件は決めても、

→ 全件利用されたら原資はいくらになるのか
→ 何件利用されると予算上限に達するのか
→ どれだけ売上を作れば採算が合うのか
→ 1件あたり最低いくら購入してもらう必要があるのか

まで計算されていないケースがある。

本ツールでは、

クーポン施策を「値引額」ではなく「総予算・必要売上」まで落とし込む。
