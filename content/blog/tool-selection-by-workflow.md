RakuKitには画像・商品テキスト・HTML・CSV・リサーチと、目的の異なるツールが数十個あります。「便利そうだけど、自分は今どれを使えばいいのか分からない」という声が多いため、この記事では**業務フローの各タイミングで使うツール**をリスト形式で一覧化しました。上から順に、店舗運営の実務が進む流れに沿って並んでいます。

## 1. 新商品を出品する前（データ準備）

商品登録データを整える段階です。

- 商品画像をリサイズ・圧縮したい → [画像リサイズ・圧縮](/tools/image)
- 商品名の文字数・バイト数・機種依存文字を確認したい → [商品名文字数チェッカー](/tools/product-name)
- 全角/半角が混在していないか確認したい → [全角／半角文字数チェック](/tools/zenkaku-hankaku)
- 登録エラーの原因になる禁止文字を事前に見つけたい → [禁止文字／機種依存文字チェック](/tools/forbidden-chars)
- 商品説明のHTMLを整形・タグ除去したい → [HTML整形](/tools/html-format) / [HTMLタグ除去](/tools/html-strip)
- 商品CSVの文字コード変換・列抽出・重複削除・一括置換・Excel変換をしたい → [CSV文字コード変換](/tools/csv-encoding) / [CSV列抽出](/tools/csv-extract) / [CSV重複削除](/tools/csv-dedupe) / [CSV一括置換](/tools/csv-replace) / [CSV→Excel変換](/tools/csv-excel)
- 大量の商品CSVを条件指定でまとめて修正したい → [CSV商品一括編集](/tools/csv-bulk-edit)

## 2. 商品ページを公開・SEO改善する

商品名やページ内容を「検索されるかたち」に整える段階です。

- 顧客が実際に検索している言葉を洗い出したい → [サジェストキーワード収集](/tools/suggest)
- サジェストの変化（NEW/OUT）を継続的に追いたい → [サジェスト差分・トレンド](/tools/suggest-trend)
- 商品名に狙ったキーワードを入れられているか確認したい → [商品名SEOチェッカー](/tools/product-seo-check)
- 複数商品の商品名を優先順位付けで見直したい → [商品名一括SEO診断](/tools/bulk-seo-check)
- 競合のタイトルで使われているキーワードを分析したい → [楽天SEO競合タイトル分析ツール](/tools/title-seo-analysis)
- キーワード候補ごとの競合の強さを比較したい → [楽天SEOキーワード競合度チェッカー](/tools/keyword-competition-checker)

## 3. 価格・利益を設計する

値付けや値引きが利益にどう影響するかを事前に計算する段階です。

- 送料・ポイント・クーポン込みで1注文あたりの利益を知りたい → [利益・値引きシミュレーター](/tools/profit-simulator)
- 値引き後に必要な販売数増加率を知りたい → [値引き必要販売数シミュレーター](/tools/discount-volume)
- 値上げしても許容できる販売減少率を知りたい → [値上げ許容販売減少率シミュレーター](/tools/price-increase)
- 送料無料化・ポイント増額の採算ラインを知りたい → [送料無料化必要販売増加率シミュレーター](/tools/free-shipping-volume) / [最大ポイント倍率チェッカー](/tools/max-point-rate)
- 在庫処分の値下げ上限を知りたい → [在庫消化値下げ上限・利益許容額シミュレーター](/tools/inventory-markdown-limit)

## 4. 広告（RPP）を運用する

RPP広告の出稿・調整をする段階です。

- 商品別のROAS・CVR・CPCを一括で確認したい → [RPP広告分析](/tools/rpp-analysis)
- このCPCで入札して成立するCVRを事前に知りたい → [RPP必要CVRシミュレーター](/tools/rpp-required-cvr)
- CVR別に許容できる最大CPCを一覧で見たい → [CVR別CPC上限マトリクス](/tools/cpc-limit-matrix)
- 赤字ラインまであと何クリックか把握したい → [RPP赤字まであと何クリックシミュレーター](/tools/rpp-click-runway)
- 広告予算を増やす前に必要売上・ROASを逆算したい → [広告予算増額シミュレーター](/tools/ad-budget-scaling)

## 5. 販促・クーポン施策を設計する

クーポンやまとめ買い施策を打つ前の採算チェックです。

- ポイント還元とクーポンのどちらが得か比較したい → [ポイント vs クーポン比較](/tools/promotion-comparator)
- クーポンで採算が取れる最低購入金額を知りたい → [クーポン最低購入金額シミュレーター](/tools/coupon-minimum-spend)
- まとめ買いクーポンで本当に利益が増えるか確認したい → [まとめ買いクーポン採算チェッカー](/tools/bulk-purchase-coupon)
- クーポン施策全体の必要売上・原資を計算したい → [クーポン予算・必要売上シミュレーター](/tools/coupon-budget)
- 送料無料ライン到達に必要な客単価を知りたい → [送料無料ライン目標・必要客単価シミュレーター](/tools/free-shipping-threshold-aov)

## 6. セール・売上目標を立てる

月間・イベントごとの数値目標を決める段階です。

- 売上目標から必要な注文数・アクセス数を逆算したい → [売上目標逆算シミュレーター](/tools/sales-target-reverse)
- SALE期間中に必要な販売数・日販を知りたい → [SALE目標売上・必要販売数シミュレーター](/tools/sale-target)
- 月間利益目標から必要売上・販売数を逆算したい → [月間利益目標・必要売上／販売数シミュレーター](/tools/profit-target)
- 固定費の損益分岐販売数を知りたい → [固定費回収・必要販売数シミュレーター](/tools/fixed-cost-break-even)
- 新規顧客の必要獲得数を逆算したい → [売上目標達成・必要新規顧客数シミュレーター](/tools/new-customer-target)

## 7. 競合・市場をリサーチする

出店ジャンルの状況や競合の動きを把握する段階です。

- キーワードで競合商品の価格・レビュー・送料をまとめて分析したい → [競合商品分析ツール](/tools/competitor-analysis)
- 自社価格が市場内でどのポジションか確認したい → [価格ポジショニング分析ツール](/tools/price-position-analysis)
- ジャンル内の空白市場（競争が手薄な領域）を探したい → [空白市場発見ツール](/tools/market-gap-finder)
- レビュー件数が少ない今なら参入できるか判断したい → [レビュー参入障壁分析ツール](/tools/review-barrier-analysis)
- 競合ショップの商品構成・主力商品を把握したい → [競合ショップ商品構成分析ツール](/tools/shop-composition-analysis)
- 価格・新商品の変化を継続的に監視したい → [タイムセール・価格監視ツール](/tools/price-watch) / [新商品・競合商品変化検知ツール](/tools/change-detection)
- 複数店舗展開時の設定差異（価格・送料・ポイント）を確認したい → [13店舗 商品設定差異チェックツール](/tools/shop-diff-checker)

## 8. 在庫を消化する

シーズン終わりや過剰在庫の処分を計画する段階です。

- 期限内に在庫を消化するための必要日販を知りたい → [在庫消化に必要な販売数・価格シミュレーター](/tools/inventory-clearance)
- 利益を守れる値下げの上限を知りたい → [在庫消化値下げ上限・利益許容額シミュレーター](/tools/inventory-markdown-limit)

## 9. レビュー・リピート施策を強化する

購入後のファン化・信頼構築の段階です。

- 目標評価に到達するのに必要な★5件数を知りたい → [レビュー評価目標・必要★5件数シミュレーター](/tools/review-rating-target)
- 低評価が付いた影響と回復に必要な件数を知りたい → [低評価レビュー1件の影響・回復必要件数シミュレーター](/tools/low-rating-impact)
- リピート率目標に必要なリピーター数を知りたい → [リピート率目標・必要リピーター数シミュレーター](/tools/repeat-rate-target)
- リピート売上目標に必要な再購入件数を知りたい → [リピート売上目標・必要再購入件数シミュレーター](/tools/repeat-sales-target)

## まとめ

ツールは「良さそうだから使う」のではなく、「今どの業務フェーズにいるか」から逆算して選ぶと迷いません。

1. 出品準備 → 画像・文字・CSV系ツール
2. SEO・商品ページ改善 → サジェスト・SEOチェック系ツール
3. 価格・利益設計 → シミュレーター系ツール
4. 広告運用 → RPP系ツール
5. 販促・クーポン → 施策採算チェック系ツール
6. 目標設計 → 逆算シミュレーター系ツール
7. 競合・市場リサーチ → 分析ツール群
8. 在庫消化 → 在庫系シミュレーター
9. レビュー・リピート → レビュー/リピート系シミュレーター

迷ったときはこの記事をブックマークして、該当するフェーズの項目から選んでください。
