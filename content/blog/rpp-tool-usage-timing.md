RPP広告は日々の入札・予算管理が数字勝負になる施策です。「なんとなく様子を見る」ではなく、決まったタイミングで数字を確認する運用にすると赤字を防ぎやすくなります。ここでは機能説明ではなく、**「こういうタイミングで、このツールを使う」**というリストにまとめました。

## RPP広告を新しく出稿する前

入札額を決める前の採算チェックです。

- このCPCで入札して成立するために必要なCVRを事前に知りたい → [RPP必要CVRシミュレーター](/tools/rpp-required-cvr)
- 商品ページの実際のCVR水準に対して、許容できる最大CPCを知りたい → [CVR別CPC上限マトリクス](/tools/cpc-limit-matrix)

## 定期的な広告レポートを確認するとき（週次・月次）

出稿中の商品を継続的にチェックするタイミングです。

- 商品別のROAS・CVR・CPCを一括で確認し、対応が必要な商品を洗い出したい → [RPP広告分析](/tools/rpp-analysis)
- 現在の広告費・クリック数・注文数から、赤字ラインまであと何クリックか把握したい → [RPP赤字まであと何クリックシミュレーター](/tools/rpp-click-runway)

## 広告費を増額するか検討しているとき

予算を増やす前に、成立条件を確認するタイミングです。

- 増額後の広告予算を成立させるために必要な売上・ROASを逆算したい → [広告予算増額シミュレーター](/tools/ad-budget-scaling)

## CPCが急に上がった・入札競争が激化したと感じたとき

コスト悪化のサインが出たときの緊急チェックです。

- 上がったCPCでも赤字にならないか、必要CVRを再計算したい → [RPP必要CVRシミュレーター](/tools/rpp-required-cvr)
- 現状のペースで赤字ラインまでどれくらい余裕があるか確認したい → [RPP赤字まであと何クリックシミュレーター](/tools/rpp-click-runway)

## まとめ：タイミングは4つ

1. 新規出稿前 → RPP必要CVRシミュレーター＋CPC上限マトリクス
2. 週次・月次レポート確認時 → RPP広告分析＋クリック残数シミュレーター
3. 予算増額検討時 → 広告予算増額シミュレーター
4. CPC高騰時 → 必要CVR再計算＋クリック残数確認

広告を「出しっぱなし」にせず、この4つのタイミングで必ず数字を見直す運用にすることが赤字回避の基本です。
