価格変更は一度実行すると取り消しにくい施策です。「なんとなくの感覚」ではなく、変更前に必ず数字で確認する運用にしておくと失敗しにくくなります。ここでは機能説明ではなく、**「こういうタイミングで、このツールを使う」**というリストにまとめました。

## セールやキャンペーンで値引きを検討しているとき

値引き幅を決める前の採算チェックです。

- 送料・ポイント・クーポンまで含めた1注文あたりの利益を確認したい → [利益・値引きシミュレーター](/tools/profit-simulator)
- 値引き後に利益を維持するために必要な販売数増加率を知りたい → [値引き必要販売数シミュレーター](/tools/discount-volume)

## 原価が上がって値上げを検討しているとき

値上げによる販売数の落ち込みがどこまで許容できるかの確認です。

- 値上げ後も利益を維持できる販売数の許容減少率を知りたい → [値上げ許容販売減少率シミュレーター](/tools/price-increase)

## 送料無料化やポイント倍率アップを検討しているとき

施策実行前に必要な販売増加を試算するタイミングです。

- 送料無料化後に利益を維持できる必要販売増加率を知りたい → [送料無料化必要販売増加率シミュレーター](/tools/free-shipping-volume)
- 利益率を維持できる最大ポイント負担率を知りたい → [最大ポイント倍率チェッカー](/tools/max-point-rate)

## 自社の値付けが競合と比べて高いか安いか気になったとき

価格を変える前に、市場内のポジションを客観視するタイミングです。

- 市場価格の中央値・価格帯構成の中で自社商品がどこにいるか確認したい → [価格ポジショニング分析ツール](/tools/price-position-analysis)

## 在庫処分のために値下げを検討しているとき

利益を守れる値下げ幅の上限を先に決めておくタイミングです。

- 許容できる利益減少額から、最低販売価格と最大値下げ率を逆算したい → [在庫消化値下げ上限・利益許容額シミュレーター](/tools/inventory-markdown-limit)

## まとめ：タイミングは5つ

1. 値引き検討時 → 利益・値引きシミュレーター＋値引き必要販売数シミュレーター
2. 値上げ検討時 → 値上げ許容販売減少率シミュレーター
3. 送料無料化・ポイント増額検討時 → 送料無料化シミュレーター＋最大ポイント倍率チェッカー
4. 値付けの妥当性確認時 → 価格ポジショニング分析
5. 在庫処分の値下げ検討時 → 値下げ上限シミュレーター

価格を「変える前」に必ずどれか1つを通す、というルールにしておくのがおすすめです。
