競合・市場調査ツールは種類が多く、「とりあえず眺める」使い方だと効果が出にくい分野です。ここでは機能説明ではなく、**「こういうタイミングで、このツールを使う」**というリストにまとめました。

## 新しいジャンル・商品カテゴリへの参入を検討しているとき

土地勘のない市場に入る前の下調べです。

- そのジャンルの価格帯・レビュー傾向・ショップ集中度をまず把握したい → [競合商品分析ツール](/tools/competitor-analysis)
- 競争が手薄な価格帯・属性の組み合わせ（空白市場）を探したい → [空白市場発見ツール](/tools/market-gap-finder)
- レビュー資産の少ない今なら参入しやすいか判断したい → [レビュー参入障壁分析ツール](/tools/review-barrier-analysis)
- ジャンル内の属性ごとに価格・レビュー・競争度がどう違うか把握したい → [商品属性×競争力分析ツール](/tools/attribute-competition-analysis)

## 自社の値付けが妥当か不安になったとき

価格を変える前に市場内の立ち位置を確認するタイミングです。

- 市場価格の中央値・価格帯構成の中で自社商品がどこにいるか確認したい → [価格ポジショニング分析ツール](/tools/price-position-analysis)
- 競合の送料無料・ポイント施策がどの程度一般化しているか把握したい → [ポイント・送料無料競争分析ツール](/tools/promotion-competition-analysis)

## 定期的に競合の動きを見張りたいとき

一度きりの調査ではなく、継続監視したい場面です。

- 登録した競合商品の価格・SALE・ポイント倍率の変化を検出したい → [タイムセール・価格監視ツール](/tools/price-watch)
- 競合ショップに新商品が出ていないか、既存商品の設定が変わっていないか確認したい → [新商品・競合商品変化検知ツール](/tools/change-detection)
- 競合価格の推移を端末内に蓄積して自社価格ポジションを継続確認したい → [価格調査ツール](/tools/price-research)

## 特定の競合ショップを詳しく分析したいとき

競合1社の全体像を把握するタイミングです。

- そのショップの取扱商品・価格帯・レビュー資産・主力商品を分析したい → [競合ショップ商品構成分析ツール](/tools/shop-composition-analysis)

## 出稿・出品するキーワードの競合度を見極めたいとき

商品名やRPP入札キーワードを決める前の確認です。

- キーワード候補ごとの検索商品数・競合度・競合余地を比較したい → [楽天SEOキーワード競合度チェッカー](/tools/keyword-competition-checker)

## まとめ：タイミングは5つ

1. 新ジャンル参入検討時 → 競合商品分析＋空白市場発見
2. 値付けに不安があるとき → 価格ポジショニング分析
3. 継続監視したいとき → 価格監視＋変化検知
4. 特定競合を深掘りしたいとき → 競合ショップ商品構成分析
5. キーワード選定時 → キーワード競合度チェッカー

「なんとなく相場観をつかむ」のではなく、意思決定の直前に使うツールとして位置づけると効果が出ます。
