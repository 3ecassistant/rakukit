出品準備系のツールは地味ですが、使うタイミングを決めておくと「登録してからエラーに気づく」「あとで全商品を直す羽目になる」といった手戻りを防げます。ここでは機能説明ではなく、**「こういうタイミングで、このツールを使う」**というリストにまとめました。

## 新商品を登録する直前

登録データを最終チェックするタイミングです。

- 商品画像のサイズ・容量を規定内に収めたい → [画像リサイズ・圧縮](/tools/image)
- 商品名の文字数・バイト数を超過していないか確認したい → [商品名文字数チェッカー](/tools/product-name)
- 全角/半角の表記ゆれをそろえたい → [全角／半角文字数チェック](/tools/zenkaku-hankaku)
- 登録エラーの原因になる機種依存文字が混ざっていないか確認したい → [禁止文字／機種依存文字チェック](/tools/forbidden-chars)
- 商品説明のHTMLを見やすく整形したい → [HTML整形](/tools/html-format)

## 大量の商品を一括更新するとき

キャンペーンや仕様変更で、既存商品をまとめて修正するタイミングです。

- 特定列の値を条件付きで一括置換・追加・削除したい → [CSV商品一括編集](/tools/csv-bulk-edit)
- CSVの文字コードが原因で文字化けする・取り込めない → [CSV文字コード変換](/tools/csv-encoding)
- 必要な列だけを抜き出して別システムに渡したい → [CSV列抽出](/tools/csv-extract)
- 重複行を検出して整理したい → [CSV重複削除](/tools/csv-dedupe)
- CSVを人が見やすいExcel形式に変換して確認・共有したい → [CSV→Excel変換](/tools/csv-excel)

## 他社ECサイトからHTML説明文を移植するとき

外部で作成した説明文を楽天用に取り込むタイミングです。

- 余計な装飾タグを外してテキストだけ抽出したい → [HTMLタグ除去](/tools/html-strip)
- 崩れたHTMLをインデント付きで整形して読みやすくしたい → [HTML整形](/tools/html-format)

## 複数店舗を運営していて、設定を横並びで確認したいとき

同一商品を複数店舗で販売している場合の整合性チェックです。

- 店舗間で価格・送料・商品名・ポイント倍率にズレがないか確認したい → [13店舗 商品設定差異チェックツール](/tools/shop-diff-checker)

## まとめ：タイミングは4つ

1. 新商品登録の直前 → 画像・文字数・禁止文字チェック
2. 大量商品の一括更新時 → CSV系ツール
3. 外部HTMLの移植時 → HTML整形・タグ除去
4. 複数店舗運営時 → 設定差異チェックツール

「登録ボタンを押す前に必ず通す」チェックリストとして使うのが一番効果的です。
