売上・KPI計画系のツールは「目標を決めるとき」に一気にまとめて使うのがコツです。ここでは機能説明ではなく、**「こういうタイミングで、このツールを使う」**というリストにまとめました。

## 月初・期初に売上目標を立てるとき

期間の数値目標を、根拠を持って設計するタイミングです。

- 売上目標から必要な注文数・アクセス数・日割り目標を逆算したい → [売上目標逆算シミュレーター](/tools/sales-target-reverse)
- 利益目標から必要な売上額・販売数を逆算したい → [月間利益目標・必要売上／販売数シミュレーター](/tools/profit-target)
- 固定費を回収できる最低販売数（損益分岐点）を把握しておきたい → [固定費回収・必要販売数シミュレーター](/tools/fixed-cost-break-even)

## 新規顧客獲得の施策を計画するとき

広告費や販促費をかけて新規を獲得する前の数値設計です。

- 売上目標達成に必要な新規顧客数を逆算したい → [売上目標達成・必要新規顧客数シミュレーター](/tools/new-customer-target)

## リピーター施策・CRM施策を計画するとき

既存顧客への施策を打つ前の目標設定です。

- リピート率目標に必要なリピーター人数を逆算したい → [リピート率目標・必要リピーター数シミュレーター](/tools/repeat-rate-target)
- リピート売上目標に必要な再購入件数を逆算したい → [リピート売上目標・必要再購入件数シミュレーター](/tools/repeat-sales-target)

## 広告予算やクーポン予算を積み増すとき

投資判断の前に、成立条件を確認するタイミングです。

- 広告予算増額後に必要な売上・ROASを逆算したい → [広告予算増額シミュレーター](/tools/ad-budget-scaling)

## 客単価を引き上げる施策を検討するとき

まとめ買いや送料無料ラインなど、客単価向上策の目標設定です。

- 客単価目標に必要なまとめ買い注文の比率を逆算したい → [客単価目標・必要まとめ買い率シミュレーター](/tools/bulk-purchase-rate)
- 送料無料ライン到達に必要な客単価差額を知りたい → [送料無料ライン目標・必要客単価シミュレーター](/tools/free-shipping-threshold-aov)

## まとめ：タイミングは5つ

1. 月初・期初の目標設定時 → 売上目標逆算＋利益目標＋損益分岐点
2. 新規獲得施策計画時 → 必要新規顧客数シミュレーター
3. リピーター施策計画時 → リピート率・リピート売上シミュレーター
4. 予算積み増し検討時 → 広告予算増額シミュレーター
5. 客単価向上施策検討時 → まとめ買い率＋送料無料ラインシミュレーター

「今月はいくら売る」だけでなく「そのために何が何件必要か」まで分解してから施策に着手すると、後で帳尻が合わなくなるのを防げます。
