楽天市場のSEO対策ツールは種類が多く、「サジェスト収集」「商品名SEOチェッカー」「競合タイトル分析」などどれも便利そうに見えますが、いつ使うべきかが分からないと放置されがちです。この記事では機能の説明ではなく、**「こういうタイミングで、このツールを使う」**という形で、使いどころだけをリストにまとめました。

## 新商品を登録するとき

商品名を決める前が、SEO対策の効果が最も出やすいタイミングです。

- 商品名に入れるキーワード候補を集めたい → [サジェストキーワード収集](/tools/suggest)
- 決めた商品名が狙ったキーワードを実際にカバーできているか確認したい → [商品名SEOチェッカー](/tools/product-seo-check)
- 同じジャンルの競合がどんなキーワードでタイトルを作っているか知りたい → [楽天SEO競合タイトル分析ツール](/tools/title-seo-analysis)
- 候補キーワードのうち、どれが狙い目（競合が少ない）か知りたい → [楽天SEOキーワード競合度チェッカー](/tools/keyword-competition-checker)

## アクセス・売上が落ちてきたと感じたとき

「以前は売れていたのに最近伸びない」商品を見直すタイミングです。

- 顧客の検索語が変わっていないか確認したい → [サジェスト差分・トレンド](/tools/suggest-trend)
- 既存の商品名が今のサジェストとズレていないか確認したい → [商品名SEOチェッカー](/tools/product-seo-check)
- 手持ちの商品全体で、どれから見直すべきか優先順位をつけたい → [商品名一括SEO診断](/tools/bulk-seo-check)

## 季節・シーズンの切り替わり前

需要が変わる季節商品ほど、事前のキーワード見直しが効きます。

- シーズン前に新しいサジェストワードが出てきていないか確認したい → [サジェスト差分・トレンド](/tools/suggest-trend)
- シーズン商品の商品名を毎年使い回さず、最新のキーワードに合わせて調整したい → [サジェストキーワード収集](/tools/suggest) → [商品名SEOチェッカー](/tools/product-seo-check)

## 月次・四半期の定期メンテナンスとして

売れ行きに関係なく、決まった頻度でチェックする運用向けです。

- 主力商品のキーワードカバー率を定期的にモニタリングしたい → [商品名SEOチェッカー](/tools/product-seo-check)
- 保有商品全体で見直し漏れがないか棚卸ししたい → [商品名一括SEO診断](/tools/bulk-seo-check)
- サジェストの新語・消えた語を継続的に記録しておきたい → [サジェスト差分・トレンド](/tools/suggest-trend)

## 新しいジャンル・カテゴリに参入するとき

土地勘のない市場でキーワードから設計し直すタイミングです。

- そのジャンルでどんな語が検索されているかゼロから洗い出したい → [サジェストキーワード収集](/tools/suggest)
- 上位表示している競合がどんなタイトル構成をしているか把握したい → [楽天SEO競合タイトル分析ツール](/tools/title-seo-analysis)
- キーワードごとの競合の強さを比べて、勝負しやすい語を選びたい → [楽天SEOキーワード競合度チェッカー](/tools/keyword-competition-checker)

## まとめ：タイミングは5つ

1. 新商品登録時 → サジェスト収集＋商品名SEOチェッカー
2. 売上が落ちたとき → サジェスト差分＋商品名SEOチェッカー
3. シーズン切り替わり前 → サジェスト差分・トレンド
4. 定期メンテナンス（月次/四半期） → 商品名一括SEO診断
5. 新ジャンル参入時 → サジェスト収集＋競合タイトル分析

「気になったら使う」のではなく、上記のどれかに当てはまったタイミングで使う、というルールにしておくと、ツールの使い忘れがなくなります。
